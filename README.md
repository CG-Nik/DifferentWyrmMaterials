# DifferentWyrmMaterials
This mod serves as an API mod and patch mod that adds a Distribution to the Wyrm and Crystal Wyrm for their materials, allowing them to drop different types of leather.  Other mods can use these Distributions to add new leather types that can drop from Wyrms.  
This mod needs to be on both the Client and Server (Technically, the Client version of the mod does nothing, but it causes a bunch of errors if you don't have it due to how mods reference it on the server, so it's required anyways).  
Requires https://github.com/CG-Nik/CustomDistributionAPI on both the Client and Server.  

This is an unofficial, fan-made mod for A Township Tale. This mod is not affiliated with or endorsed by the owners or developers of A Township Tale.
